# Wealth360 Scroll World production pack

## Recommended production decision

- **Concept:** Assurance World
- **Architecture:** A, one continuous forward chain
- **Desktop:** 16:9, 720p during preview, upgrade only after the chain is approved
- **Mobile:** use the accessible technical fallback first; commission a native 9:16 chain only if the desktop world proves its value
- **Calibration:** one GPT Image 2 still plus one five-second Seedance 2 Mini preview
- **Paid status:** not started. Calibration requires explicit approval because it consumes Kie.ai credits.

## Calibration acceptance criteria

The calibration is accepted only if all of these are true:

1. The still feels like premium executive architecture, not a generic clay toy or sci-fi dashboard.
2. The palette matches the frozen preamble closely enough to chain future scenes.
3. The five-second preview moves in one stable forward direction with no cut or reversal.
4. The final second is calm enough to extract a clean boundary frame.
5. There is meaningful negative space for live HTML copy.
6. No text, logos, malformed furniture, duplicated objects, flicker or unstable geometry appear.

If the test fails, change one variable at a time. Do not batch the other six scenes until the art direction and camera behavior both pass.
